# AICHONG 线程交接模板

更新时间：2026-05-28
用途：每个线程结束时按这个模板交接，避免结果只留在聊天里。

## 给 Codex 的使用规则

- 不需要机械填满长篇，但关键项不能省。
- 如果本线程改了重要规则、风险判断或上线结论，要写回对应文档。
- 涉及钱、短信、结算、权限、生产配置时，必须明确写“是否已得到主人确认”。
- 主人说“交接上线”时，只整理上次上线完成之后、本线程准备纳入本轮上线的改动；不要继续改代码。
- 如果不确定上次上线完成点，必须先说明“不确定本轮起点”，并列出自己能确认的改动范围。


判断规则：

- 没发现 bug、没改代码，只是有未验证项：通常不需要修 bug 线程，需要上线总控判断是否补测。
- 发现明确 bug 且测试线程没有修复：需要修 bug 线程。
- 测试线程修了代码：必须复测本轮，并写清楚改动文件和验证结果。
- 未验证项涉及真实付款、真实短信、真实结算、权限或生产配置：不能自动补测，必须先问主人或交上线总控判断。
