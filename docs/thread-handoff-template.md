# AICHONG 线程交接模板

更新时间：2026-05-28
用途：每个线程结束时按这个模板交接，避免结果只留在聊天里。

## 给 Codex 的使用规则

- 不需要机械填满长篇，但关键项不能省。
- 如果本线程改了重要规则、风险判断或上线结论，要写回对应文档。
- 涉及钱、短信、结算、权限、生产配置时，必须明确写“是否已得到主人确认”。
